# Frontend Components

Complete guide to the React components that power Dapp-Forge's user interface.

## 🎨 Frontend Architecture

Dapp-Forge uses a modern React architecture with Redux for state management and Bootstrap for styling.

## 🎯 Common Patterns

### Redux Connection

All components connect to Redux store:

```javascript
import { connect } from 'react-redux'

class MyComponent extends Component {
  // Component logic
}

function mapStateToProps(state) {
  return {
    account: state.web3.account,
    // ... other state
  }
}

export default connect(mapStateToProps)(MyComponent)
```

### Event Listeners

Components subscribe to blockchain events:

```javascript
async componentWillMount() {
  await this.loadBlockchainData()
  this.subscribeToEvents()
}

subscribeToEvents() {
  this.props.exchange.events.Trade({})
    .on('data', (event) => {
      this.props.dispatch(orderFilled(event))
    })
}
```

### Conditional Rendering

Show loading states and data:

```javascript
render() {
  return (
    <div>
      {this.props.showBalance ? (
        <BalanceComponent />
      ) : (
        <Spinner />
      )}
    </div>
  )
}
```

## 🔄 Data Flow

### 1. User Action
```
User clicks button
  ↓
Component handler function called
  ↓
Action dispatched to Redux
```

### 2. Redux Processing
```
Action received by reducer
  ↓
State updated
  ↓
Connected components re-render
```

### 3. Blockchain Interaction
```
Component dispatches async action (thunk)
  ↓
Interaction function called
  ↓
Web3 transaction sent
  ↓
Event emitted by smart contract
  ↓
Event listener updates Redux state
  ↓
Components re-render with new data
```

## 🛠️ Component Communication

### Parent to Child (Props)

```javascript
// Parent
<Balance 
  account={this.props.account}
  web3={this.props.web3}
  exchange={this.props.exchange}
/>

// Child
class Balance extends Component {
  render() {
    const { account, web3, exchange } = this.props
    // Use props
  }
}
```

### Child to Parent (Callbacks)

```javascript
// Parent
<NewOrder onOrderCreated={this.handleOrderCreated} />

// Child
this.props.onOrderCreated(orderData)
```

### Sibling Components (Redux)

```javascript
// Component A dispatches action
this.props.dispatch(orderCreated(order))

// Component B receives update via Redux
function mapStateToProps(state) {
  return {
    orders: state.exchange.orders
  }
}
```

## 🐛 Common Issues & Solutions

### Issue 1: Component Not Updating

**Problem:** Redux state changes but component doesn't re-render

**Solution:** Check `mapStateToProps` is correct
```javascript
function mapStateToProps(state) {
  return {
    // Make sure you're selecting the right state
    orders: state.exchange.allOrders
  }
}
```

### Issue 2: Event Listener Memory Leak

**Problem:** Event listeners not cleaned up

**Solution:** Remove listeners on unmount
```javascript
componentWillUnmount() {
  if (this.subscription) {
    this.subscription.unsubscribe()
  }
}
```

### Issue 3: Async State Updates

**Problem:** State update after component unmount

**Solution:** Check if mounted before updating
```javascript
_isMounted = false

componentDidMount() {
  this._isMounted = true
}

componentWillUnmount() {
  this._isMounted = false
}

async loadData() {
  const data = await fetchData()
  if (this._isMounted) {
    this.setState({ data })
  }
}
```
