# Navbar Component

The top navigation bar displaying application branding, user account information, and network status.

## 📋 Overview

**File:** `src/components/Navbar.js`

**Purpose:**
- Display application logo and title
- Show connected Ethereum account
- Display current network name
- Provide consistent navigation header

## 🎨 Visual Structure

```
┌─────────────────────────────────────────────────────────┐
│  🦊 Dapp-Forge                        Sepolia  0x742...0bEb │
└─────────────────────────────────────────────────────────┘
     Logo & Title                       Network    Account
```

## 🏗️ Component Code

```javascript
import React, { Component } from 'react'
import { connect } from 'react-redux'
import { accountSelector } from '../store/selectors'

class Navbar extends Component {
  render() {
    return (
      <nav className="navbar navbar-expand-lg navbar-dark bg-primary">
        <div className="container-fluid">
          {/* Brand/Logo */}
          <a className="navbar-brand" href="/">
            <img 
              src="/logo.png" 
              width="30" 
              height="30" 
              className="d-inline-block align-top" 
              alt="Dapp-Forge Logo"
            />
            {' '}
            Dapp-Forge
          </a>

          {/* Account & Network Info */}
          <ul className="navbar-nav ms-auto">
            <li className="nav-item">
              <a 
                className="nav-link small"
                href={`https://etherscan.io/address/${this.props.account}`}
                target="_blank"
                rel="noopener noreferrer"
              >
                {this.props.account ? (
                  <span>{this.shortenAddress(this.props.account)}</span>
                ) : (
                  <span>Connect Wallet</span>
                )}
              </a>
            </li>
          </ul>
        </div>
      </nav>
    )
  }

  shortenAddress(address) {
    if (!address) return ''
    return `${address.slice(0, 6)}...${address.slice(-4)}`
  }
}

function mapStateToProps(state) {
  return {
    account: accountSelector(state)
  }
}

export default connect(mapStateToProps)(Navbar)
```

## 🐛 Common Issues

### Issue 1: Address Not Displaying

**Problem:** Account shows as "Connect Wallet" even when connected

**Solution:** Check Redux state
```javascript
// Debug in browser console
console.log(store.getState().web3.account)

// Ensure selector is correct
const accountSelector = state => state.web3.account
```

### Issue 2: Etherscan Link Wrong Network

**Problem:** Link goes to mainnet even on testnet

**Solution:** Pass network ID
```javascript
<a href={this.getEtherscanLink(account, networkId)}>
  View on Etherscan
</a>

getEtherscanLink(address, networkId) {
  const networks = {
    1: 'etherscan.io',
    11155111: 'sepolia.etherscan.io'
  }
  const domain = networks[networkId] || 'etherscan.io'
  return `https://${domain}/address/${address}`
}
```

### Issue 3: Navbar Overlapping Content

**Problem:** Content appears behind navbar

**Solution:** Add margin or padding
```css
body {
  padding-top: 70px; /* Navbar height */
}

/* Or */
.content {
  margin-top: 20px;
}
```
