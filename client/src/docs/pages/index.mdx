# Dapp-Forge Documentation

Welcome to **Dapp-Forge** - A fully decentralized exchange (DEX) platform built on Ethereum blockchain technology.

## 🎯 What is Dapp-Forge?

Dapp-Forge is a decentralized application (DApp) that enables **peer-to-peer token trading** without intermediaries. Built on Ethereum smart contracts, it provides a trustless, transparent, and secure platform for exchanging ERC-20 tokens with ETH.

### Key Features

- 🔒 **Trustless Trading** - No intermediaries, trade directly with other users
- 🌐 **Transparent** - All transactions recorded on blockchain
- 💰 **Non-Custodial** - You control your assets at all times
- ⚡ **Real-time** - Live order books and instant trade execution
- 📊 **Professional Charts** - ApexCharts integration for price visualization
- 🔐 **Secure** - Auditable smart contracts with safety mechanisms

## 🚀 Quick Start

Get started in 5 minutes:
```bash
# 1. Clone the repository
git clone https://github.com/Hrsh111/Dapp-Forge.git

# 2. Navigate to client directory
cd Dapp-Forge/client

# 3. Install dependencies
npm install

# 4. Start development server
npm start
```

The app will open at `http://localhost:3000`

## 📝 Quick Examples

### Example 1: Place a Buy Order
```javascript
// User wants to buy 10 tokens for 0.1 ETH each
await exchange.methods.makeOrder(
  tokenAddress,                      // Token to receive
  web3.utils.toWei('10', 'ether'),   // Amount: 10 tokens
  ETHER_ADDRESS,                     // Give ETH
  web3.utils.toWei('1', 'ether')     // Total: 1 ETH
).send({ from: account })
```

### Example 2: Fill an Order
```javascript
// Fill order #5 from the order book
await exchange.methods.fillOrder(5)
  .send({ from: account })
```

### Example 3: Check Balance
```javascript
// Check token balance on exchange
const balance = await exchange.methods
  .balanceOf(tokenAddress, account)
  .call()

console.log(`Balance: ${web3.utils.fromWei(balance)} tokens`)
```
